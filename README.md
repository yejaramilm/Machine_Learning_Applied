# ST1613 — Aprendizaje Automático (Machine Learning) Aplicado

## Descripción del curso

Este curso ofrece una introducción práctica al Aprendizaje Automático (Machine Learning), cubriendo desde el procesamiento de datos hasta técnicas modernas de aprendizaje supervisado, no supervisado, redes neuronales y modelos de lenguaje de gran escala (LLMs) y Transformers. A lo largo del curso, los estudiantes aplicarán los conceptos vistos en talleres prácticos y desarrollarán un short paper como proyecto final.

- **Código:** ST1613
- **Día:** Miércoles
- **Horario:** 17:00 – 20:00 (3 horas)
- **Modalidad de evaluación:** talleres, entregas parciales, parcial, presentación final y short paper.
